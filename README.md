Automated Box Transport System: SolidWorks Design & MATLAB Analysis
Complete mechanical design, solid modeling, physical wooden prototyping, and engineering analysis for an automated box transport and handling system.
Key Objectives
Solid Modeling & CAD: Developed detailed 3D parts, assemblies, and mechanical layouts using SolidWorks.
Physical Prototyping: Fabricated and assembled a functional scale physical model using wood and structural components.
Engineering Analysis: Performed numerical modeling, data processing, and performance simulations using MATLAB.
Tools & Contents
Tools & Software: SolidWorks, MATLAB, Prototyping Wood & Materials, Mechanical Assemblies.
